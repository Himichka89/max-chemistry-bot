# MAX Chemistry Bot v1

Первая версия чат-бота «Уроки химии | с Надеждой Романовной».

## Что уже есть
- Главное меню: 8, 9, 10, 11 классы
- ОГЭ и ЕГЭ
- Игры и тесты
- Запись на занятия
- Кнопка канала MAX: https://max.ru/se14525189_biz
- Webhook для постоянной работы

## Размещение на Render
1. Распакуйте ZIP.
2. Создайте новый репозиторий GitHub и загрузите туда файлы.
3. В Render создайте Web Service из этого репозитория.
4. Build command: `pip install -r requirements.txt`
5. Start command: `gunicorn app:app`
6. В Environment добавьте:
   - `MAX_BOT_TOKEN` — ваш токен MAX (никому его не отправляйте).
   - `WEBHOOK_SECRET` — придумайте строку минимум 5 символов, только латинские буквы, цифры, `_` или `-`, например `chem_bot_2026_secret`.
7. После успешного Deploy откройте адрес вашего сервиса с `/setup` на конце, например:
   `https://ИМЯ-СЕРВИСА.onrender.com/setup`
8. Если увидите `"success": true`, подписка Webhook создана.
9. Откройте бота в MAX, нажмите «Начать» или напишите `меню`.

Важно: MAX использует API `https://platform-api2.max.ru` и токен передаётся через заголовок Authorization.
